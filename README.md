## Overview

Antinode Clear Preset Hub is a standalone preset browser and organizer for the Antinode Clear VST synthesizer, providing a searchable grid of all factory and user presets with waveform preview, category tagging, and one-click load via plugin parameter recall — making navigating Clear's extensive preset library faster than the built-in browser.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Antinode Clear Preset Hub** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Preset Grid** | Visual grid of presets with waveform thumbnail and category tag |
| **Text Search** | Search preset names, descriptions, and tags simultaneously |
| **Waveform Preview** | Audio waveform preview for each preset before loading |
| **One-Click Load** | Load any preset into the active Clear plugin instance instantly |
